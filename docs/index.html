How it works

A LangGraph state graph runs plan → agents → synthesize. The planner picks agents from their A2A cards and MCP tool schemas; LangGraph's Send fans the calls out in parallel; the writer answers only from the tool results.

Guardrails

Planner output is validated against each tool's schema, with keyword routing as a fallback. Every tool call has a timeout and a cache, a failed agent still yields a partial answer, and requests are rate limited.
