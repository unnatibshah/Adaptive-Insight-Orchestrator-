Event log

    Plan

    A LangGraph planner (gpt-oss-20b on Groq) reads each agent's A2A card and MCP tool schema and returns a plan. The plan is checked against the schemas, with keyword routing as a fallback.

    Fan out

    LangGraph's Send runs the agent calls in parallel. Each agent owns an MCP server backed by a keyless public API, with timeouts and caching on every call.

    Answer

    The writer (gpt-oss-120b) answers only from the tool results. If an agent fails, you still get the rest; if the model is down, a template answer is built from the same data.
